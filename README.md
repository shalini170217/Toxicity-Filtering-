# Toxicity-Filtering- is a NLP based model , which filters out the comments based on certain level of toxicity .
The dataset is taken from kaggle (jigsaw-toxic-comment-classification-challenge)
the link to the dataset is Github: https://github.com/nicknochnack/CommentToxicity/blob/main/jigsaw-toxic-comment-classification-challenge/train.csv/train.csv
